# Jenwille John V. Robias — Portfolio

Personal portfolio site for Jenwille John V. Robias, a freelance web developer and virtual assistant based in Pasig City, PH.

**Live site:** https://robias-porfolio.vercel.app

## Featured work

- **[Sidequest](https://github.com/robszzs/sidequest)**: a personal game diary web app (HTML, CSS, JavaScript, Vercel)
- **[BalikGamit](https://github.com/robszzs/BalikGamit)**: RTU's lost and found platform (Python, Streamlit), built as a team project
- **Data entry & tracking**: Google Sheets work samples

## Project structure

```
.
├── index.html            # The whole site (single page)
├── assets/
│   ├── css/styles.css    # Styles, with light and dark themes
│   ├── js/main.js        # Scroll animations, nav highlight, copy-email
│   ├── images/           # Profile photo and project screenshots
│   └── files/resume.pdf  # Downloadable résumé
└── README.md
```

## Running locally

It's a static site with no build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deployment

Hosted on Vercel. Each push to `main` deploys automatically.
